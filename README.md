# Outfits — телеграм-бот с подборками одежды

Присылает в личку подборки вещей под твой стиль, размер и бюджет.
Анкета вкуса живёт внутри Telegram как Mini App: выбираешь стили по фотографиям,
категории, размеры и диапазон цен — бот запоминает и подбирает по этому профилю.

## Что внутри

```
bot/
  __main__.py     запуск: веб-сервер + бот + расписание
  config.py       настройки из .env
  db.py           SQLite: профили и память о показанном
  auth.py         проверка подписи initData из Mini App
  server.py       отдаёт мини-апп, принимает профиль
  bot.py          команды и отправка подборок
  styles.py       16 стилей -> поисковые запросы и слова-маркеры
  ranker.py       отбор по бюджету/размеру/стоп-листу и сортировка
  digest.py       сборка подборки
  sources/wb.py   поиск по Wildberries + ссылки на фото
docs/
  index.html      анкета (Telegram Mini App), её раздаёт GitHub Pages
refresh_examples.py   обновляет обложки стилей по живым данным WB
```

## Бренды

На Wildberries ищутся **Mango**, **Befree**, **EKONIKA** и **Calzedonia**.

**Lime и Nume на Wildberries отсутствуют** — то, что выдаётся по их названиям,
это другие продавцы (`Modalime`, `Emberens`, `XseniyaLime`). Их нужно забирать
с собственных сайтов брендов; модуль для этого пока не написан.

## Запуск

### 1. Бот у @BotFather

Напиши [@BotFather](https://t.me/BotFather), команда `/newbot`, задай имя.
В ответ придёт токен вида `123456789:AA...` — он понадобится дальше.

### 2. Настройки

```bash
cp .env.example .env
```

Впиши в `.env`:

- `BOT_TOKEN` — токен от BotFather
- `PUBLIC_URL` — публичный **HTTPS**-адрес, по которому открывается мини-апп

Telegram открывает Mini App только по HTTPS, поэтому `localhost` не подойдёт.
Для локальной отладки подними туннель:

```bash
cloudflared tunnel --url http://localhost:8080
```

и положи выданный адрес в `PUBLIC_URL`.

### 3. Установка и старт

```bash
uv venv --python 3.12 && uv pip install -e .
```

```bash
.venv/bin/python -m bot
```

Дальше в Telegram: `/start` → «Заполнить анкету» → сохранить → «✨ Подборка».

## Команды

| Команда | Что делает |
|---|---|
| `/start` | знакомство и кнопка анкеты |
| `/podborka` | собрать подборку прямо сейчас |
| `/nastroiki` | переписать вкус, размеры, бюджет |
| `/pause` / `/resume` | остановить и вернуть рассылку |

Сама по себе рассылка идёт **по понедельникам в 10:00**, а каждые 6 часов бот
проверяет, не подешевело ли что-то из твоего вкуса больше чем на 40%.
Расписание меняется в `bot/config.py`.

## Деплой

Нужен хостинг, который даёт HTTPS-домен и не усыпляет процесс
(бот работает на long polling и держит расписание).

- **Railway / Render**: подключить репозиторий, команда запуска `python -m bot`,
  переменные `BOT_TOKEN` и `PUBLIC_URL` — в настройках сервиса. `PORT` платформа
  подставляет сама.
- База — SQLite в `data/`. На хостингах с эфемерным диском подключи volume,
  иначе профиль будет теряться при передеплое.

## Как работает подбор

1. Из выбранных стилей и категорий собираются поисковые фразы (`styles.py`).
2. По каждой фразе — запрос к Wildberries отдельно по каждому бренду.
   Бренд сверяется строго: на WB полно похожих названий, которые к оригиналу
   отношения не имеют.
3. Отсев (`ranker.py`): цена вне диапазона, нет твоего размера в наличии,
   слово из стоп-листа в названии, скидка ниже порога, меньше двух отзывов
   или рейтинг ниже 3.8.
4. Оценка: совпадение слов-маркеров стиля, размер скидки, рейтинг, отзывы.
5. Разнообразие: не больше трети подборки на одну категорию.
6. Уже показанное не повторяется — кроме случая, когда цена упала ещё на 15%.

## Авторские права и данные

Копий чужих фотографий проект **не хранит**. Обложки стилей и снимки в подборках
показываются по прямым ссылкам на серверы Wildberries — у нас только адреса,
которые лежат в `bot/examples.py`. Если товар снимут с продажи и ссылка умрёт,
достаточно запустить `refresh_examples.py`.

Бот хранит `chat_id`, имя, ник и предпочтения. Пока пользователь один и это
владелец бота, это личные и семейные нужды — 152-ФЗ на такую обработку
не распространяется (ст. 1, ч. 2, п. 1). **Если открывать бота другим людям**,
появляются обязанности оператора персональных данных: согласие, политика
обработки, уведомление РКН и хранение базы на серверах в России (ст. 18, ч. 5).
Render и Railway для этого не подойдут — нужен российский хостинг.

Ссылки на товары обычные, без партнёрских меток, поэтому рекламой не являются
и маркировки не требуют. Подключишь партнёрскую программу — понадобится ERID
и отчётность в ЕРИР.

## Ограничения

- Wildberries отдаёт `429` при частых запросах, поэтому запросы притормаживаются.
  Первая подборка собирается около минуты, дальше быстрее: адреса картинок
  кешируются в `data/baskets.json`.
- Публичного API у WB нет — используется тот же поиск, что и на сайте.
  Если он поменяется, чинить в `bot/sources/wb.py`.
