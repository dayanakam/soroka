# Знак «Сороки»

`logo.svg` — исходник, `logo-512.png` — аватарка для Telegram.

Оригинальная работа: геометрия нарисована с нуля в SVG, чужих изображений,
клипарта и шрифтов внутри нет. Исключительные права принадлежат владельцу бота.

Птица в профиль, длинный ступенчатый хвост — главная примета сороки, в клюве
находка. Цвета те же, что в анкете: белый `#FFFFFF`, почти чёрный `#111113`,
тёплый акцент `#D99A2B`.

Птица вписана в круг с запасом: Telegram обрезает аватарку по окружности,
и хвост не должен попадать под срез.

Перерисовать PNG после правки исходника:

    "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
      --screenshot=brand/logo-512.png --window-size=512,512 brand/export.html

Посмотреть, как знак держится на мелких размерах, — открыть `preview.html`.
